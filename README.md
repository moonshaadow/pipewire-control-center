# PipeWire Control Center

A versatile and streamlined configuration tool for PipeWire on Linux.

## Overview

PipeWire Control Center (PCC) provides a clean, intuitive interface for managing your PipeWire audio setup. Whether you're a daily desktop user looking for simple device management or a pro-audio enthusiast needing precise control over buffers and routing, PCC adapts to your needs.

## Features

- **Device Management** — Switch default devices, adjust volumes, and monitor active streams
- **Audio Settings** — Configure sample rates and buffer sizes with presets
- **Configuration Profiles** — Save and restore your preferred audio setups
- **AES67 Support** — Native AES67 session configuration with PTP synchronization
- **System Status** — Real-time monitoring with event logging
- **Bilingual Interface** — French and English
